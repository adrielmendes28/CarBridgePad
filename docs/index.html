CarBridgePad

Game controllers that keep working on CarPlay.

Download .deb Source code

Description

When CarBridge shows a game on the car screen, iOS treats the game as if it were in the background, so your controller stops working on CarPlay. CarBridgePad lets installed games keep receiving controller input (DualSense, Xbox, MFi) while they run on CarPlay.

How to use

  • Install, then force-quit the game and open it again.
  • Open the game on CarPlay through CarBridge and play with your controller.
  • There are no settings.

Notes

  • Keep the iPhone unlocked. With the iPhone locked, iOS stops delivering controller input.
  • Input lag comes mostly from the CarPlay stream and Bluetooth. Wired CarPlay and a cool iPhone help.
  • Tested with GTA: San Andreas and a DualSense. Other games that use Apple's GameController framework should work.
